# 🌿 El Duende — GovRisk Santa Cruz

Sistema de alerta temprana, simulación de turbiones y monitoreo hidrometeorológico en tiempo real para el Río Piraí y el Departamento de Santa Cruz.

---

## 📌 Eje: GovRisk (Gobernación de Santa Cruz)
Protección ciudadana integral: monitoreo preventivo diario (calor y río seguro) y transición automática a centro de alerta temprana ante desastres naturales.

## 🚀 Rama de Desarrollo
Esta rama (`feat/victor-architecture`) contiene la base arquitectónica y de integración para migrar los módulos geoespaciales (GeoPlan) y el motor de telemetría/sensores (AgroLog).
